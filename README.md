# Neon Jump

Juego de plataformas desarrollado en Python con Pygame como proyecto de la facultad.

El objetivo es avanzar la mayor distancia posible saltando entre plataformas que se generan dinámicamente. A medida que el jugador asciende, la dificultad aumenta y las plataformas se vuelven más pequeñas.

## Características

- Movimiento horizontal y salto del personaje.
- Animaciones de movimiento y salto.
- Plataformas generadas aleatoriamente.
- Dificultad progresiva según la altura alcanzada.
- Cámara con desplazamiento vertical.
- Sistema de puntuación.
- Menú principal con opciones.
- Control de volumen de la música.
- Pantalla de Game Over y reinicio de partida.

## Tecnologías

- Python
- Pygame
